# ComfyUI Lokken VideoTools

A standalone video post-processing node for ComfyUI, derived from the Turbo
Post Processing node in [Elvax Nodes](https://github.com/younestft/Elvax-nodes).

## Status

Initial repository setup only. The node implementation has not been added yet,
and this repository is not yet an installable ComfyUI node pack or a published
Comfy Registry package.

The planned node will retain video post-processing and expose configurable
H.264 encoder presets and profiles. It will use a distinct node identifier so
it can coexist with Elvax Nodes.
